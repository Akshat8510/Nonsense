# 🧠 Problem Reminder (1 line)

> Copy a linked list where each node has `next` and `random`, and **new list must NOT touch old list**

---

# 🧩 Example we’ll use

```text
7 (old) → 13 (old) → 11 (old)
```

Random:

```text
13 (old).random → 7 (old)
11 (old).random → 13 (old)
```

---

# 🚀 STEP 1: Create copy nodes (insert in between)

We don’t make a separate list yet.
We **mix them** first.

### Before:

```text
7(old) → 13(old) → 11(old)
```

### After inserting copies:

```text
7(old) → 7'(new) → 13(old) → 13'(new) → 11(old) → 11'(new)
```

👉 Every old node now has its copy right next to it

---

# 🚀 STEP 2: Fix random pointers

Now we assign `random` for new nodes.

### Trick (VERY IMPORTANT):

```text
new.random = old.random.next
```

---

### Apply it:

#### Case 1:

```text
13(old).random → 7(old)
```

So:

```text
13'(new).random → 7'(new)
```

Because:

```text
7(old).next = 7'(new)
```

---

#### Case 2:

```text
11(old).random → 13(old)
```

So:

```text
11'(new).random → 13'(new)
```

---

# 🚀 STEP 3: Separate the lists

Now we split them.

### Current mixed:

```text
7(old) → 7'(new) → 13(old) → 13'(new) → 11(old) → 11'(new)
```

---

### After separation:

#### Original:

```text
7(old) → 13(old) → 11(old)
```

#### New copy:

```text
7'(new) → 13'(new) → 11'(new)
```

---

# ✅ Final Result

New list:

* has same values ✔️
* same structure ✔️
* all pointers inside new list ✔️
* no connection to old list ✔️

---

# 🧠 Why this works (important intuition)

Because:

* Every old node sits right before its copy
* So we can easily jump from old → new using `.next`

---

# 💥 Final memory trick

> “Insert copy → use old to fix random → split”

---

# 😏 Quick check
👉 “Why not just copy directly?”

You say:

> “Because random pointers may point to nodes not created yet.”

# 🧠 What hints are trying to say (translated)

---

# 💡 Hint 1 (basic idea)

> “Copy nodes while iterating, but don’t create duplicates”

👉 Meaning:

If multiple nodes point to same node using `random`,
you must NOT create multiple copies of it.

---

### 🧠 Why?

```text
A(old).random → C(old)
B(old).random → C(old)
```

👉 You need:

```text
A'(new).random → C'(new)
B'(new).random → C'(new)
```

NOT:

```text
two different C'(new) ❌
```

---

# 💡 Hint 2 (easy solution using extra space)

> Use a map: (old → new)

---

### 🧠 Idea:

```text
Map:
7(old) → 7'(new)
13(old) → 13'(new)
```

---

### Steps:

1. Create all new nodes
2. Use map to assign:

```text
new.next = map.get(old.next)
new.random = map.get(old.random)
```

---

👉 Easy but uses **extra space O(n)**

---

# 💡 Hint 3 (smart solution, no extra space)

> “Interweave nodes”

---

### 🧠 This is the REAL trick

Instead of map, we do:

```text
A(old) → A'(new) → B(old) → B'(new)
```

---

### Why this helps?

Because:

```text
old.next = new
```

👉 So from any old node, you can directly reach its copy

---

# 💡 Hint 4 (final magic)

> Use interweaving to set random

---

### 🧠 Key formula:

```text
(new).random = (old).random.next
```

---

### Why?

Because:

```text
(old).random → X(old)
```

And:

```text
X(old).next = X'(new)
```

👉 So:

```text
(old).random.next = X'(new)
```

---

# 🚀 FULL FLOW (combine all hints)

---

## STEP 1: Interweave

```text
A(old) → A'(new) → B(old) → B'(new)
```

---

## STEP 2: Fix random

```text
A'(new).random = A(old).random.next
```

---

## STEP 3: Separate lists

```text
Original: A(old) → B(old)
Copy:     A'(new) → B'(new)
```

---

# 🧠 Final understanding

* Hint 1–2 → brute force (use map)
* Hint 3–4 → optimized (no extra space)
