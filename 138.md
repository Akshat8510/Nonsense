# 🧠 Problem Reminder (1 line)

> Copy a linked list where each node has `next` and `random`, and **new list must NOT touch old list**

---

# 🧩 Example we’ll use

```text
7 (old) → 13 (old) → 11 (old)
```

Random:

```text
13 (old).random → 7 (old)
11 (old).random → 13 (old)
```

---

# 🚀 STEP 1: Create copy nodes (insert in between)

We don’t make a separate list yet.
We **mix them** first.

### Before:

```text
7(old) → 13(old) → 11(old)
```

### After inserting copies:

```text
7(old) → 7'(new) → 13(old) → 13'(new) → 11(old) → 11'(new)
```

👉 Every old node now has its copy right next to it

---

# 🚀 STEP 2: Fix random pointers

Now we assign `random` for new nodes.

### Trick (VERY IMPORTANT):

```text
new.random = old.random.next
```

---

### Apply it:

#### Case 1:

```text
13(old).random → 7(old)
```

So:

```text
13'(new).random → 7'(new)
```

Because:

```text
7(old).next = 7'(new)
```

---

#### Case 2:

```text
11(old).random → 13(old)
```

So:

```text
11'(new).random → 13'(new)
```

---

# 🚀 STEP 3: Separate the lists

Now we split them.

### Current mixed:

```text
7(old) → 7'(new) → 13(old) → 13'(new) → 11(old) → 11'(new)
```

---

### After separation:

#### Original:

```text
7(old) → 13(old) → 11(old)
```

#### New copy:

```text
7'(new) → 13'(new) → 11'(new)
```

---

# ✅ Final Result

New list:

* has same values ✔️
* same structure ✔️
* all pointers inside new list ✔️
* no connection to old list ✔️

---

# 🧠 Why this works (important intuition)

Because:

* Every old node sits right before its copy
* So we can easily jump from old → new using `.next`

---

# 💥 Final memory trick

> “Insert copy → use old to fix random → split”
